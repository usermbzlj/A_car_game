# APEX TUNER — 高拟真赛车调校模拟

一款完整可玩的浏览器赛车游戏，核心卖点是**极高自由度的车辆引擎调校系统**。玩家可深入调整喷油量、点火正时、涡轮增压、空燃比、齿比、悬挂、差速器、刹车平衡、ECU 映射与散热等参数，实时影响马力、扭矩曲线、温度、耐久与操控反馈。

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5173` 即可游玩。

生产构建：

```bash
npm run build
npm run preview
```

## 游戏模式

| 模式 | 说明 |
|------|------|
| **练习** | 自由练习，3 条赛道，无压力熟悉操控与调校 |
| **计时赛** | 单圈挑战，追求最快圈速 |
| **锦标赛** | 三站系列赛，与 5 名 AI 车手争夺积分冠军 |
| **自由调校** | Dyno 测功模式，静态测试引擎，实时查看马力/扭矩曲线 |

## 调校系统

### 引擎
- **喷油量** — 影响输出上限，过高增加爆震风险
- **点火正时** — 最佳约 10° BTDC，偏离降低效率
- **涡轮增压** — 0.5–2.5 bar，显著提升马力
- **空燃比 (AFR)** — 最佳约 12.5，过浓/过稀均损失动力

### ECU / 散热
- **ECU 油门映射** — 控制 throttle response 激进程度
- **转速限制** — 6000–9000 RPM
- **散热器 / 机油冷却** — 降低水温油温，保护耐久

### 底盘
- **悬挂硬度 / 高度** — 影响抓地力与稳定性
- **LSD 差速锁止** — 改善弯中牵引
- **刹车平衡** — 前后制动力分配
- **终传比** — 影响各档极速与加速

### 齿比
- 6 档独立齿比可调，配合终传比精细匹配赛道

## 技术栈

- TypeScript + Vite
- HTML5 Canvas 2D 渲染
- Web Audio API 引擎声浪合成
- 纯前端，无需后端

├── game/
│   ├── Game.ts          # 主循环与模式逻辑
│   ├── Physics.ts       # 车辆物理
